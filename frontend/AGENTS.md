# Email Campaign Manager — Frontend

## Overview

This is the web frontend for the Email Campaign Manager. It is a TanStack Start
application built with React, TypeScript, and Tailwind CSS.

The app supports four views:

- Google Sign In
- Dashboard
- Create Campaign
- Campaign History

Authentication is handled entirely by the backend; the frontend never stores
credentials and only redirects to the backend's Google OAuth endpoint.

## Development

```sh
npm install
npm run dev
```

The frontend talks to the backend API through `src/lib/api.ts`. Point
`VITE_API_BASE_URL` at the backend URL when the API lives on a different origin
(e.g. `VITE_API_BASE_URL=https://api.example.com`).

## Conventions

- File-based routing under `src/routes/` (TanStack Router). `routeTree.gen.ts`
  is generated by the build tool and must not be edited by hand.
- All server communication goes through the typed client in `src/lib/api.ts`.
  Pages never fetch directly and never use hardcoded data.
- When the backend is unavailable, pages render a clean error state (see
  `src/components/states.tsx`).
